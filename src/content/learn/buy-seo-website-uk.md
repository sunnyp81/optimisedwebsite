## What a Genuine SEO Website Includes

When you buy an SEO-optimised website, the value is in the invisible architecture — not the visible design. Here's what should be included:

**Keyword research and topical mapping.** 50 to 200 keywords clustered by search intent, mapped into a hub-and-spoke page structure through proper [keyword research](/services/keyword-research/). This determines which pages exist and how they connect.

**Original content written for search intent.** Every page targets a specific keyword cluster with content that answers the searcher's question. Not AI filler, not manufacturer copy, not repurposed blog posts.

**Per-page JSON-LD schema.** Organisation, WebSite, Article, FAQPage, HowTo, BreadcrumbList — the structured data that tells Google what each page is about and how entities relate to each other.

**Technical SEO foundations.** Canonical URLs, XML sitemaps, robots.txt, heading hierarchy, Core Web Vitals in green, accessible HTML. The boring stuff that separates sites that rank from sites that look nice.

**Hosting and deployment.** Edge-cached globally (Cloudflare Pages or Vercel), sub-second first paint, zero JavaScript overhead unless it earns its bytes.

**Source code ownership.** GitHub repository, hosting account, and domain — all yours. No vendor lock-in, no monthly platform fees.

## What You Should NOT Be Paying For

- Monthly "SEO maintenance" on a brand-new site (the build should not need maintenance)
- Proprietary CMS access fees
- "Premium plugins" bundled into the price
- Stock photography or generic design assets
- Ongoing hosting at agency markup (Cloudflare Pages is free)
